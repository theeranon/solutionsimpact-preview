มุมที่ 1 — Plugin ที่ควรตัดหรือแทนที่

แทนได้แน่นอน google-site-kit → ใส่ Code ตรงใน si-blog-redesign.php

ปัญหาปัจจุบัน: Site Kit ฉีด 2 อย่างบน frontend จริงๆ คือ GA4 tag (GT-PHRZMJXS via gtag.js) และ GTM container ที่สอง (GTM-T7LVRVFH) ซึ่งทำให้มี GTM 2 container โหลดพร้อมกัน (GTM-PSD6BMK จาก si-blog-redesign + GTM-T7LVRVFH จาก Site Kit)

วิธีแทนที่: ถ้า GA4 manage ผ่าน GTM-PSD6BMK อยู่แล้ว — ปิด Site Kit ได้เลย ไม่ต้องเขียน Code เพิ่ม ถ้า GA4 ไม่ได้อยู่ใน GTM ให้เพิ่ม snippet เดียวใน si-blog-redesign.php แล้วปิด Site Kit

⚠️ ต้องตรวจก่อน

เข้า GTM-PSD6BMK → Tags ดูว่ามี GA4 tag (GT-PHRZMJXS) อยู่หรือเปล่า ถ้ามี → ปิด Site Kit ได้เลย 100% ถ้าไม่มี → ให้ผมเพิ่ม 3 บรรทัดใน si-blog-redesign.php แล้วค่อยปิด Site Kit

แทนได้แน่นอน ai-engine → ปิดได้เลย (ไม่มี Frontend presence เลย)

Fetch ทุกหน้าแล้วไม่พบ reference ของ ai-engine แม้แต่ครั้งเดียว ไม่มี chatbot widget, ไม่มี JS, ไม่มี CSS โหลด Plugin active อยู่เฉยๆ กิน memory PHP ทุก request

Action: ปิดใน WP Admin → Plugins ได้เลย ถ้าต้องการ AI chatbot ในอนาคต ค่อยกลับมา enable

พิจารณา seo-engine — จ่ายเงินแล้ว แต่ยัง output ว่าง

ยืนยัน fetch ล่าสุด: <meta class="mwseo-meta" name="description" content=""> ยังอยู่ทุกหน้า SEO Engine ต้องการ Excerpt ในแต่ละหน้า — เพราะ Bricks Builder ไม่ได้เขียน content ลง post_content มาตรฐาน

Action ที่ทำได้เลย: เข้า Edit Page แต่ละหน้า → แท็บ Basic → กรอก Excerpt → Save 4 หน้าหลักแก้ได้ใน 10 นาที

ถ้าจะ automate: ผมเพิ่ม filter ใน si-blog-redesign.php ให้ดึง description จาก custom field ที่กำหนดเป็น fallback ได้เลย ไม่ต้องกรอกทุกหน้า

Admin Only — เก็บไว้ถ้าใช้ bulk-edit-categories-tags-premium, wp-sheet-editor-* (3 ตัว)

ทั้ง 4 ตัวนี้ไม่มีผลต่อ Frontend เลย ใช้จัดการข้อมูลใน Admin เท่านั้น ถ้าไม่ได้ใช้ batch edit บ่อยๆ → ปิดไว้ เปิดตอนจะใช้

มุมที่ 2 — Performance & Speed

🔴 Critical Poppins โหลดทุก weight — 18 variants ที่แทบไม่ได้ใช้

Bricks โหลด Poppins ทุก weight ตั้งแต่ 100 ถึง 900 ทั้ง italic และ normal รวม 18 variants ในหน้าเดียว แต่ grep ทั้งเว็บเจอ Poppins ใช้จริงแค่ครั้งเดียว (น่าจะเป็น Heading ตัวเดียว)

/* ปัจจุบัน — โหลดทั้งหมด */
family=Poppins:ital,wght@0,100;0,200;...0,900;1,100;...1,900

/* ควรเป็น — เฉพาะที่ใช้จริง */
family=Poppins:wght@600;700

แก้: Bricks Builder → Settings → Custom Fonts / Google Fonts → จำกัด Poppins ให้เหลือแค่ weight ที่ใช้จริง ประหยัด HTTP request + ลด render-blocking font ได้ชัดเจน

🔴 Critical GTM โหลด 2 Container พร้อมกันทุกหน้า

GTM-PSD6BMK (si-blog-redesign) + GTM-T7LVRVFH (google-site-kit) โหลดพร้อมกันทุกหน้า ทุก GTM container = 1 HTTP request + JS execution + dataLayer init ซ้ำ

แก้: ตรวจว่า GTM-T7LVRVFH มี tag อะไรบ้าง ถ้า GA4 อยู่ใน GTM-PSD6BMK อยู่แล้ว → ปิด Site Kit แก้ปัญหานี้ได้เลย

🔴 Critical FluentForm JS โหลดทุกหน้าแม้ไม่มี Form

fluentform-advanced.js + form-submission.js โหลดทุกหน้า รวมถึงหน้า Blog และ Public ที่ไม่มี form อยู่เลย

homepage
28 FluentForm references (มี form จริง — โอเค)
inhouse-training
28 references (มี form จริง — โอเค)
/public/
17 references — ส่วนใหญ่ CSS inline form style โหลด JS ฟรี
/blog/
17 references — โหลด JS ฟรี

แก้: FluentForm Settings → Global Settings → ติ๊ก "Load styles/scripts only when shortcode used" ถ้า option นี้มี หรือผมเพิ่ม conditional loading ใน si-blog-redesign.php ได้

🟡 Medium โหลด 2 Carousel Libraries พร้อมกัน (Swiper + Splide)

swiper.min.js และ splide.min.js โหลดคู่กันทุกหน้า ปกติ Bricks ใช้ Splide เป็น default carousel แต่ Swiper โหลดมาด้วยเสมอ ถ้าไม่มี Swiper widget ในหน้าไหน → เป็น dead weight

ตรวจ: Bricks Builder → Elements ที่ใช้ ถ้าไม่มี Slider element ที่ใช้ Swiper → ไปตั้ง Bricks Settings ให้ไม่โหลด Swiper globally

🟡 Medium Page Titles ไม่มี Keyword — SEO เสีย
Homepage title
"Home | Solutions IMPACT" — Google ไม่รู้ว่าเว็บทำอะไร
Inhouse title
"Inhouse Training | Solutions IMPACT" — พอได้แต่ไม่มี year/benefit
Public title
"Public | Solutions IMPACT" — แย่มาก ไม่มี keyword เลย
Blog title
"Blog | Solutions IMPACT" — missed opportunity

แก้: ผ่าน SEO Engine → ตั้ง title template per-page เช่น Homepage → "SolutionsIMPACT — Transformation Consulting & AI Training สำหรับองค์กร"

🟡 Medium WordPress Version ถูก expose ใน <head>

<meta name="generator" content="WordPress 6.9.4"> อยู่ใน <head> ทุกหน้า บอก attacker ว่าใช้ WP version อะไร

แก้: เพิ่มใน si-blog-redesign.php 1 บรรทัด:

remove_action('wp_head', 'wp_generator');
🟡 Medium OG Description ว่างเปล่า — Share บน LINE/Facebook ไม่มีข้อความ

Homepage og:description = "" (ว่าง), og:image = "" (ว่าง) ทุกครั้งที่ share ลิงค์บน LINE/Facebook จะไม่มีรูปและไม่มีคำอธิบาย — เสีย CTR ชัดเจน

แก้: SEO Engine → ตั้ง OG description per-page หรือผมเพิ่ม fallback ใน si-blog-redesign.php

มุมที่ 3 — Positioning: Transformation Consult ≠ Training House

วิเคราะห์จาก heading, copy, และ schema ทุกหน้า — ปัญหาหลักคือ ข้อความบนเว็บยังพูดถึงตัวเองเป็น "สถาบันฝึกอบรม" อยู่หลายจุด ทั้งที่ positioning จริงๆ คือ Transformation Consulting

🔴 Positioning Gap Copy บน Inhouse Training ยังใช้คำ "สถาบันฝึกอบรม" 2 ครั้ง

พบใน inhouse-training page: "SOLUTIONS IMPACT สถาบันฝึกอบรม ของเรามุ่งเน้นจัดฝึกอบรม Inhouse Training" และ "เราคือสถาบัน การพัฒนา บุคลากร"

คำว่า "สถาบันฝึกอบรม" / "สถาบัน" ทำให้ถูกจัดอยู่ใน mental category เดียวกับ training provider ทั่วไป แทนที่จะเป็น strategic partner ที่ drive business transformation

แนะนำ — แทนที่ด้วย

"SolutionsIMPACT เป็น Transformation Partner ที่ช่วยองค์กรวาง Strategy และสร้าง Capability ด้าน AI & Future Skills ให้เกิดผลลัพธ์จริง ไม่ใช่แค่การอบรม"

🔴 Positioning Gap H1 Homepage ไม่พูดถึง Transformation — พูดถึงแค่ Reskill

H1 ปัจจุบัน: "อัพเกรดทีมของคุณในปี 2026 ให้มีทักษะสำคัญแห่งอนาคต ที่ทุกคนทำงานเก่งขึ้น 10 เท่า"

นี่คือ messaging ของ Training Provider — เน้น skills เน้น "ทำงานเก่ง" Transformation Consultant จะพูดถึง Business Outcomes, Organizational Change, และ ROI ไม่ใช่ individual skills

แนะนำ — Frame ใหม่

"เราไม่ได้แค่สอน — เราเปลี่ยนวิธีที่องค์กรของคุณทำงาน ด้วย AI & Future Skills ที่วัดผลได้จริง"

🔴 Positioning Gap Inhouse H1 ยังใช้ "ปี 2025" — ล้าสมัย

"Inhouse Training หลักสูตรจัดฝึกอบรม ภายในองค์กร ปี 2025!" — ตอนนี้ 2026 แล้ว ทำให้ดูไม่ได้ update เนื้อหา กระทบ credibility

แก้: แก้เป็น 2026 ในหน้า Bricks Editor ทันที

🟡 Missing ไม่มี Case Study / Business Outcome บนเว็บ

Transformation Consultant พิสูจน์ตัวเองด้วย Business Results ไม่ใช่แค่ logo ลูกค้า เว็บปัจจุบันมีแค่ "ได้รับความเชื่อถือจากองค์กรชั้นนำ" แต่ไม่มี story ว่าองค์กรนั้นเปลี่ยนไปยังไง

แนะนำ: เพิ่มหน้า Case Study หรือ Success Stories อย่างน้อย 3 เคส รูปแบบ: ปัญหาก่อน → process → ผลลัพธ์ที่วัดได้ (เช่น "ลดเวลา onboarding 40%" หรือ "ทีม 50 คน adopt AI workflow ใน 3 เดือน")

🟡 Missing Schema.org ไม่มี Organization / Consulting markup

Schema JSON-LD ปัจจุบัน: "@type": "WebPage" เท่านั้น ไม่มี Organization schema ไม่มี service type ไม่มี expertise area Google ไม่รู้ว่า SI คือ Consulting firm ประเภทไหน

เพิ่ม Organization Schema

ผมเพิ่มใน si-blog-redesign.php ได้เลย — @type: ProfessionalService + knowsAbout: ["AI Transformation", "Change Management", "Corporate Training"] + address + serviceArea

🟡 Missing Blog Section ไม่ได้ communicate Thought Leadership

Blog page H1: "Insights & Perspectives" — ดีกว่า "Blog" แต่ sub-copy ไม่มี ไม่มีประโยคที่บอกว่า SI มี POV เรื่องอะไร Transformation Consultant ควรมี strong point of view ที่ push boundary ไม่ใช่แค่แชร์ knowledge

แนะนำ: เพิ่ม tagline ใต้ "Insights & Perspectives" เช่น "มุมมองของเราว่า AI จะเปลี่ยน DNA ขององค์กรในยุคถัดไป — และองค์กรของคุณควรเตรียมตัวยังไง"

💡 Opportunity "Transformation Consult" มีแค่ใน og:site_description ไม่มีบนเว็บจริง

ตรวจ meta tags พบว่า og:site_description = "Transformation Consult" — คือ positioning ที่ถูกต้อง แต่คำนี้ไม่ปรากฏบน visible content ของเว็บเลย Visitor ที่เข้ามาอ่านเว็บจะไม่เห็น positioning นี้

แนะนำ: นำ "Transformation Consult" หรือ "Transformation Partner" ขึ้นมา above-the-fold ในทุกหน้าหลัก อาจเป็น sub-headline ใต้ logo หรือ hero tagline

💡 Opportunity ไม่มี Consulting Process / Methodology บนเว็บ

Training House ขายหลักสูตร — Transformation Consultant ขาย Process ปัจจุบันเว็บ SI แสดงแต่ "รายการหลักสูตร" ไม่มี section ที่อธิบายว่า SI ทำงานกับลูกค้ายังไง ตั้งแต่ Discovery → Design → Deliver → Measure

แนะนำ: เพิ่ม section "วิธีที่เราทำงานด้วยกัน" หรือ "Our Approach" ในหน้า Inhouse หรือหน้า Homepage แสดง 4-step process พร้อม outcome ที่วัดได้
